Set up your Monero identity

About a minute. Then Monero people can send your X posts xos (Monero likes), and the xos you send count.

  1. 1Your Nostr key

    If you have a Nostr signer (Alby, nos2x, Amber…), XMRadar asks it for your key. If not, XMRadar makes one for you, or you can import your own key.

    Stored unencrypted in this browser profile only (not synced or backed up, and unrecoverable if this profile or app is removed). Signs only XMRadar’s own kinds (xos, Xap receipts, Monero address, X proof) — not Copy-to-Nostr posts.
